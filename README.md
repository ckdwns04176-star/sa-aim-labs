# SA AIM LABS

서든어택 전술 · 병영 · 엔비디아 최적화 도우미 (Windows · PyWebView).
NEXON Open API 병영수첩(솔로/파티 RP · 랭크 컨디션 · 플레이 잔디 · 최근 5판 · 약점 맵),
인게임 오버레이 3종(Insert 파티 대기실 맵 밴픽 · Home 적 5명 스카우팅 · 경기 종료 토스트),
상대 스카우팅 · 타인 A+B 듀오 시너지 · 5인 맵 밴픽 · NVIDIA 계단현상/전원/게임 모드 ·
회원 로그인(이메일 · 비밀번호 찾기)과 클라우드 백업을 한 앱에 담았습니다.

**v2.0.1 — 실기 피드백 10건 + 보안 3종.** 왼쪽 레일을 6개(병영수첩 · 맵·약점 · 순위표 ·
스카우팅 · 듀오·밴픽 · 최적화)로 나누고, 화면·모달 클릭이 먹히지 않던 누락 리스너(홈 버튼 ·
설정 버튼 · 닫기 팝업 · 미로그인 로그인 안내)를 전부 복구했습니다. 오버레이 기본 단축키를
**Insert(대기실·맵 밴) / Home(상대 분석)** 으로 바꾸고, 64비트 Windows 에서 핸들이 잘려
`CreateWindowExW 실패`로 뜨던 원인(ctypes argtypes/restype 누락)을 고쳤습니다. 스카우팅은
경기 상세(match-detail) 호출을 **완전히 없애** 상대 1명당 `/user/tier` + `/match(솔로)` +
`/match(파티)` 만 병렬 조회하고, **솔로 랭크와 파티 랭크를 나눠** 티어·승률·K/D 를 보여 줍니다
(데미지 항목 제외, 응답 3초 → 1초 안팎). 티어 아이콘은 RP 가 아니라 **API 티어 이름**을 먼저
따라 별레전드가 그마 아이콘으로 뜨던 문제를 고쳤습니다. 보안은 HTML 이스케이프 전수 점검,
자동 업데이트 **SHA256 무결성 검증**(불일치 시 설치 중단·기존 exe 보존), 백업 복원 **검증 강화**
(크기·구조·version·자료형)를 넣었습니다.

**v2.0.0 — 서든 전용 전면 개편.** 에임 연습(코박스·에임랩 점수·시나리오·18단계 티어·
훈련 잔디)을 앱에서 완전히 걷어내고, 홈을 **내 랭크(솔로/파티 RP) · 최근 랭크 컨디션 ·
서든어택 플레이 잔디 · 최근 5판 · 약점 맵 TOP 3 · 오버레이/엔비디아 상태**로 다시 짰습니다.
인게임 오버레이는 pywebview 창 대신 **초경량 Win32 레이어드 창**(`WS_EX_TOPMOST |
WS_EX_NOACTIVATE | WS_EX_TRANSPARENT`, GDI+ 렌더, WM_NCHITTEST=HTTRANSPARENT)으로 바꿔
게임 포커스를 빼앗지 않고 16:9·4:3 모두에서 제 위치에 뜹니다. 파티 OCR은 신뢰도가
애매한 닉네임(0.62~0.92)을 **조회하지 않고 '확인 필요'**로 남기고, 전술 도구의 1:1 비교는
**타인 A + 타인 B 듀오 시너지**(같은 match_id 공동 승률·K/D·표본 부족 안내)로 교체했습니다.
최근 상대 팀은 매번 최신 조회 + 실패 시 저장본임을 표시하고, 화면 배율 90/100/115/125%에서
스크롤이 잘리지 않습니다. 저장소는 `RLock` 으로 동시 접근을 막고 백업·클라우드에서
API 키·Supabase 토큰·비밀번호를 제외합니다. NVAPI `NVDRS_UNICODE_STRING` 앞 4바이트
length 필드를 제거하고 `settingName[2048]` 을 복구해(구조체 12,320바이트) 드라이버
프로필 **재조회 검증 후에만** '적용 완료'로 표시합니다. 회원은 앱과 같은 Supabase
프로젝트로 로그인·회원가입·비밀번호 찾기를 쓰고, 지금은 `ENFORCE_PRO_LIMIT = False`
(무료 운영 · 전 기능 무제한)이며 이 값을 True 로 바꾸면 곧바로 무료 하루 3회 / PRO
무제한이 동작합니다.

## 소스로 실행

```bash
python -m pip install -r requirements.txt
python main.py                 # 앱 창
python main.py --serve 8710    # 브라우저 미리보기 (샘플 데이터, http://127.0.0.1:8710/index.html)
```

## Windows .exe 빌드

`main` 브랜치에 푸시하거나 Actions 에서 `Build Windows EXE` 를 수동 실행하면
`windows-latest` 에서 아래 명령으로 빌드합니다.

```powershell
pyinstaller --noconfirm --onefile --windowed --icon assets/app.ico --name "SA_Aim_Labs" ^
  --add-data "ui;ui" --add-data "assets;assets" --add-data "config.json;." ^
  --collect-all webview main.py
```

> `--collect-all webview` 는 pywebview 가 플랫폼 백엔드(edgechromium)를 동적으로 import 하기 때문에 필요합니다.

결과물: `dist/SA_Aim_Labs.exe` (Actions 아티팩트 `SA_Aim_Labs-windows`, `latest-build` 릴리즈 첨부)
실행하려면 Windows 10/11 + **Microsoft Edge WebView2 Runtime** 이 필요합니다.

## 설정

1. 앱 → **설정 · API 연동**
   - NEXON Open API 키(`open.api.nexon.com`), 서든어택 닉네임 저장 → **저장 후 전적 확인**
   - 클라우드 저장소 → **로그인 / 회원가입** (서버 주소·공개 키는 앱에 기본 내장, `고급 서버 설정` 안에 있음)
2. Supabase → **SQL Editor** 에 `supabase/schema.sql` 내용을 붙여 1회 실행
   (user_profiles 테이블 + `auth.uid() = user_id` RLS 정책)
3. 이메일 로그인/회원가입 후 **☁️ 올리기 / 내려받기** 로 PC 간 기록 동기화

## v1.1.0 — 통합 점수 · 에임랩 확충 · 추천 UX

- **통합 에임 프로필**: 코박스 · 에임랩 · 스나 · 라플 기록을 하나로 합쳐 종합 점수 · 18단계
  티어 · 5영역 밸런스 · 연속/누적 훈련일 · 일별 추이를 계산합니다(`scoring.profile_values`).
  게임별 점수 단위가 달라 영역마다 0~100 평점으로 환산해 평균합니다.
- **토글의 의미**: 왼쪽 위 `코박스/에임랩` · `스나/라플` 은 점수를 나누지 않고
  **오늘의 추천 5종 · 더 연습하기의 시나리오 필터 + 실행 프로그램**만 고릅니다.
  각 기록에는 `trainer`(game) · `weapon` · `scenarios[].raw_score` 가 남아 스나/라플 유저 판별은 그대로입니다.
- **무기별 추천 철학**: 스나 = 롱 트래킹 제외(플릭 · 마이크로 · 반응/동체 · 스위칭),
  라플 = 트래킹 2칸 · 스위칭 · 헤드라인/마이크로 · 플릭.
- **에임랩 시나리오 52종**(스나 25 · 라플 27, 중복 제외 34종 · 실제 게임 과제명) + 코박스 40종.
- **추천 5종 UX**: 각 행에 오늘 내 점수(미기록이면 `미기록`) · 클릭하면 모달에서
  점수 입력/수정 + 저장 + ▶ 게임에서 재생. 같은 시나리오를 다시 적으면 오늘 기록이 갱신(중복 없음).
- **+ 더 연습하기**: 오늘 목록에 없는 시나리오를 가장 약한 영역 위주로 3종 추가(앱을 다시 켜도 유지).
- **화면 스크롤**: `.screen` 이 창 높이를 넘으면 스크롤(다크 슬림 스크롤바) — 병영수첩 맨 아래
  약점 · 맵별 분석까지 도달. 레이더 상단 라벨이 잘리지 않게 viewBox/좌표 조정.
- **친구 순위표**: 파티 RP 도 솔로와 같은 `엠블럼 + 티어명 + RP` 형태, 같은 정렬 규칙.
- **창 크기 고정**: 서든어택 저해상도 실행 후 바탕화면 복귀 시 DPI·해상도 변화로 창이 커지지 않게
  `winutil.WindowGuard` 가 0.3초 간격으로 실측해 논리 1200×750 으로 되돌리고 화면 밖 이탈을 막습니다.

  친구·클랜 순위표 · 18단계 티어표 · 최적화 유틸. 설정은 좌측 하단 **프로필/톱니바퀴 → 설정 팝업**(4탭).
- **최적화 유틸 2버튼**: `라플 최적화` · `스나 최적화` 가 각각 계단현상 끄기(`0x00401241`)까지 병합 적용.
  적용 직후 **변경 내역 모달**(바뀐 드라이버 설정 before → after)이 뜨고, 복구 한 번이면 둘 다 되돌아갑니다.
- **당일 첫 실행 병영수첩 변화**: 직전 연습일 스냅샷과 승률·K/D·딜량·솔로/파티 RP 를 비교해 팝업으로 보여 주고
  규칙 기반 한마디 충고를 띄웁니다. `오늘 다시 보지 않기` + 병영수첩의 `변화 다시 보기` 버튼.
- **18단계 티어표**: 각 티어에 사용자 분포율(%) 막대 + 내 티어 강조. 실제 Supabase `aim_scores` 집계가
  20명 이상이면 실데이터, 그 전에는 코박스 백분위 기반 기준 분포를 씁니다. 티어를 누르면 상세 팝업.
- **맵·약점 분석**: 약점 TOP 3 클릭 → 맵 연습 팁 + 유튜브 공략 링크(외부 브라우저). 표 헤더 클릭 정렬.
- **오늘의 추천 5종 밀도**: 분류·난이도·PB·평균·다음 티어 목표·오늘 점수·진행 바를 한 행에.
  날짜가 바뀌어도 PB/평균은 기록에서 계속 계산되어 사라지지 않습니다.
- **연습 점수 추이**: 추천 행을 누르면 모달에서 역대 점수 라인 그래프(SVG)를 봅니다.
- **점수 전체 초기화**: '초기화' 입력 2차 확인. 훈련 잔디(출석)·API 키·닉네임·친구·유틸은 유지.
- **UI 정리**: 글씨 크기 상향(본문 12px+), 화면 전환 0.34초 fade+slide, 카드/행 호버 인터랙션,
  긴 설명은 `?` 툴팁으로, 윈도우 유틸은 토글 스위치, 창 닫기(X)는 항상 확인 팝업.

## 동작 메모

- **첫 로딩**: 스플래시(로고 합쳐짐 + 진행률)가 먼저 뜨고, 로컬 데이터 로드 → 티어/시나리오 계산 →
  그래픽 설정 확인(무거운 Drs 스캔은 첫 프레임 뒤로 미룸) 순으로 채워진다.
- **점수 단위**: 시나리오에 나온 실제 점수를 그대로 입력합니다(KovaaK's 152 · Aim Lab 92,500).
  레이더·티어용 0~100 평점은 `scoring.GAME_REF`(kovak 200 · aimlab 100,000)로 환산합니다.
- **계단현상 끄기**: (v1.3.0 부터 라플/스나 최적화에 자동 병합) 프로필 팩을 덮어쓴 뒤 라이브 `nvdrsdb0/1.bin` 의 서든 프로필
  `Antialiasing compatibility(0x00D55F7D)` 값을 `0x00401241` 로 **제자리 패치**합니다(2바이트, 길이·오프셋 불변).
  적용 전 Drs 폴더 전체를 백업하고, 값이 이미 `0x00401241` 이면 그대로 둡니다.
- **NEXON 호출 한도**: `test_` 키는 일일 1,000건. 경기 상세(match-detail)는 디스크에 캐시해
  이미 본 `match_id` 는 다시 부르지 않고, 순위표 갱신은 상세 호출 0건(캐시만 사용)입니다.
  한도를 넘으면 `오늘 넥슨 API 일일 호출 한도(1,000건)를 초과했어요. 자정 이후 초기화됩니다` 토스트가 뜹니다.
- **창 이동/배치**: 프레임 없는 창은 `drag_window()`(ReleaseCapture + WM_NCLBUTTONDOWN)로 OS 가 직접 옮기고,
  시작 위치는 기본 모니터 작업 영역 기준 정중앙입니다.

## 저장 위치 · 보안

- 훈련 기록·설정: `%APPDATA%\SA_Aim_Labs\data.json`
  (실행 파일 옆에 `portable.txt` 를 두면 `./data/` 로 이동 — PC방용)

- `config.json` 의 `SUPABASE_ANON_KEY` 는 클라이언트 공개용(publishable) 키입니다.
  데이터는 Supabase RLS 로 본인 행만 읽고 쓸 수 있습니다.
- NEXON `test_` 키는 발급자 본인 계정 전용입니다. 배포용으로는 `live_` 키 + 중계 서버가 필요합니다.
